3 · Three routes

Route A

Patch

Same order, same screens. Fix what's broken.

  • Cover image on mobile login (reuse CoverMasthead treatment)
  • Event + studio above Vyavasth; Vyavasth demoted to a “powered by” line
  • One line on step 1: “Takes a quick selfie to match your face”
  • Camera-capability check on step 1; “open in browser” nudge if webview
  • Second BrandLoader (in-place transition, no location.replace)
  • Trust line above the CTA

Route B · recommended

Preview first

Show the event before asking for anything. Login becomes a consequence, not a gate.

  • New screen 0: cover, event name, studio, photo count, a blurred/teaser strip
  • Login triggered by “Find my photos” — intent-driven
  • Full Name field (capture on the team screen, or skip)
  • Selfie promise + camera check moved to screen 0
  • TeamSelect runs during the face search, not before it
  • Real 0-match screen: rescan / notify me / browse all
  • Second loader

Route C

Selfie first

Face is the identity. Phone only when they want to save or return.

  • Selfie + search before any login — anonymous session
  • Results shown immediately: “We found N photos of you”
  • OTP gate moved to download / save / return-visit only
  • Name + phone from the entry path entirely
  • Consent moves to screen 1 (it's now the first ask)
