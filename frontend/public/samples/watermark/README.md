# Watermark preview sample photos

Settings > Watermark Presets previews every watermark on these four photos: the
Light choice shows `light-landscape.jpg` and `light-portrait.jpg` side by side,
the Dark choice `dark-landscape.jpg` and `dark-portrait.jpg`. The list lives in
`app/(dashboard)/dashboard/settings/watermarks/sample-photos.ts`.
